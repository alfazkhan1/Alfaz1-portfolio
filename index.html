One job per layer
The controller handles HTTP, the service holds the rules, and the repository talks to the database. Each part stays easy to test and change.

  
Check inputs early
Requests are validated before they reach business logic, and exceptions return clear errors instead of stack traces.

  
Schema under version control
Liquibase migrations make every database change repeatable, so the schema is the same on every machine.
